# CV-генератор + трекер откликов + командная работа

Веб-приложение для поиска работы: генерация адаптированного CV в **DOCX**, трекинг
откликов от отправки до офера, каталог вакансий с живым поиском по источникам и
**командная работа** — общий опыт по вакансиям, собеседованиям и отзывы.

## Возможности

- **Генератор CV** — три режима: «с опытом», «без опыта (junior)», «сгенерировать опыт» (с дисклеймером). На выходе ATS-friendly `.docx`. Вакансию можно дать ссылкой или текстом.
- **Мастер-профиль с доменами** — один профиль «на всю жизнь»: опыт и проекты помечаются доменами (IT, управление, преподавание…). Редактор — одна страница со всеми секциями.
- **Умный отбор под вакансию** — двухэтапный LLM: сначала отбирает только релевантный опыт/навыки/проекты, затем пишет CV из этого подмножества. Нерелевантное в CV не попадает.
- **Быстрый режим** — с сохранённым профилем достаточно вставить вакансию: экран-сводка → генерация, без многошагового визарда. Визард остаётся для ручного ввода.
- **Объём и оформление** — «произвольная форма» / «одна страница», 3 шаблона + акцентный цвет, свои темы и свой промт.
- **Импорт своего CV** — загрузка PDF/DOCX: текст извлекается, LLM раскладывает в структуру, файл скачивается как `.docx`.
- **Свои LLM-ключи** — DeepSeek / OpenAI / OpenRouter / любой OpenAI-совместимый endpoint. Ключи шифруются (AES-256-GCM).
- **Личный кабинет** — email + пароль (NextAuth v5, JWT), профили (мастер-данные CV, импорт `profile.yaml`/JSON).
- **Трекер откликов** — Kanban + список, настраиваемая воронка, таймлайн, заметки, контакты, собеседования, оферы.
- **Уведомления** — web-push напоминания о собеседованиях (Vercel Cron) + настройки уведомлений.
- **Каталог вакансий** — глобальный список (свои + расшаренные командой), статусы «Сохранена / Подался / Пропустить», конвертация в отклик.
- **Живой поиск вакансий** — источники: hh.ru, Хабр Карьера, Remote OK, Работа России (TrudVsem), Jooble (по ключу). Фильтр по источникам и удалёнке.
- **Telegram-лента** — админ добавляет каналы, посты отображаются как в мессенджере (со ссылками).
- **Команды** — создание/поиск/вступление, роли (владелец/участник/ментор/ревьюер), доска вакансий по компаниям, таймлайны участников, отзывы о собеседованиях (с редактированием), чат по вакансии.
- **Оферы** — фиксация ЗП/бенефитов/формата и сравнение.
- **Дашборд** — счётчики, воронка, ближайшие события, «застрявшие», последние отклики.

## Стек

Next.js 16 (App Router, Turbopack) · TypeScript (strict) · Tailwind v4 · shadcn/ui ·
react-hook-form + zod · `docx` · `cheerio` · NextAuth v5 (credentials + JWT) ·
Mongoose (MongoDB Atlas) · bcryptjs · next-themes · Vitest.

## Быстрый старт

```bash
npm install
cp .env.example .env.local   # заполнить переменные
npm run dev
```

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `MONGODB_URI` | Строка подключения MongoDB (Atlas) |
| `AUTH_SECRET` | Секрет JWT (`openssl rand -base64 32`) |
| `ENCRYPTION_KEY` | Ключ шифрования API-ключей, 32 байта |
| `DEEPSEEK_API_KEY` | Серверный LLM-ключ-фолбэк |
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` / `VAPID_SUBJECT` | Web-push (VAPID) |
| `CRON_SECRET` | Секрет Vercel Cron (напоминания) |
| `ADMIN_EMAILS` | Админ(ы) через запятую (управление Telegram-каналами). По умолчанию `blagox8@gmail.com` |
| `JOOBLE_API_KEY` / `JOOBLE_LOCATION` | (опц.) источник Jooble: ключ + локация (например `Сербия`) |
| `HH_USER_AGENT` | (опц.) User-Agent для hh.ru API |

## Команды

```bash
npm run dev            # dev-сервер
npm run build          # production-сборка
npm run start          # запуск production
npm run lint           # eslint
npm run typecheck      # tsc --noEmit
npm run test           # vitest (тесты, LLM-вызовы замоканы — без токенов)
npm run migrate:teams  # разовая миграция команд (memberIds → TeamMembership)
```

## Деплой (Vercel)

Подключить репозиторий, в `Settings → Environment Variables` задать переменные выше.
Cron для напоминаний уже описан в `vercel.json`. `trustHost` включён в коде.

> Заметка: hh.ru может блокировать IP Vercel (403) — источник помечается «недоступен»,
> остальные продолжают работать. Работает локально или с неблокируемого IP.
