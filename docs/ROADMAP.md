# ROADMAP — что сделано и что дальше

## Сделано

- **Auth** — email + пароль (NextAuth v5, credentials + JWT), лендинг + анонимный генератор.
- **LLM** — свои ключи (DeepSeek/OpenAI/OpenRouter/custom, AES-шифрование), серверный фолбэк.
- **Генерация CV** — 3 режима, мультишаг, профили (мастер-данные + импорт yaml/json), DOCX.
- **Отбор под вакансию** — двухэтапный LLM: селекция релевантного опыта → генерация только из подмножества.
- **Мастер-профиль с доменами** — теги у опыта/проектов, одностраничный редактор профиля.
- **Быстрый режим** — вакансия + профиль → генерация без визарда; «сгенерировать опыт» = только контакты + вакансия.
- **Шаблоны** — 3 пресета + акцентный цвет + пользовательские темы (шрифт, цвета, стиль заголовков).
- **Объём CV** — «произвольная форма» / «одна страница» (LLM ужимает контент).
- **Свои промты** — референсный промт для ChatGPT (копировать/вставить), сохранение и генерация по своему промту (`{{...}}`-плейсхолдеры).
- **Импорт CV** — PDF/DOCX → структура → `.docx`.
- **Трекер откликов** — kanban + список, настраиваемая воронка, таймлайн, заметки, контакты (с Telegram), собеседования, оферы, дашборд.
- **Уведомления** — web-push, настройки (что/за сколько), тестовое уведомление, cron-напоминания.
- **Каталог вакансий** — глобальный список, статусы «Сохранена / Подался / Пропустить», конвертация в отклик.
- **Живой поиск вакансий** — hh.ru, Хабр Карьера, Remote OK, Работа России, Jooble (ключ); фильтр по источникам и удалёнке.
- **Telegram-лента** — админ добавляет каналы, посты как в мессенджере.
- **Команды** — создание/поиск/вступление, роли (владелец/участник/ментор/ревьюер), доска вакансий, таймлайны, отзывы (с редактированием), чат по вакансии, активность, уведомления команде.
- **Тесты** — Vitest, LLM-вызовы замоканы (без токенов).

## Дальше (по приоритету)

1. **Надёжность**
   - Rate limit на `/api/generate`, `/api/vacancies/search`, `/api/cv-import`.
   - Retry/таймаут для LLM-вызовов.
2. **Ревью-workflow** (ядро менторской модели)
   - Задания через промты, ментор назначает ревьюера или ревьюит сам, статусы и фидбек.
   - Публичные профили менторов.
3. **Качество данных**
   - OCR для сканов PDF.
   - Дедупликация вакансий в каталоге (одна вакансия от разных людей).
4. **Расширение поиска**
   - SuperJob (бесплатный ключ), Jooble-локации, больше Telegram-каналов по умолчанию.
5. **Продукт**
   - Cover letter (сопроводительное письмо) тем же LLM-контуром.
   - CSV-экспорт откликов и бэкап данных.
   - Email-напоминания (в дополнение к web-push).
